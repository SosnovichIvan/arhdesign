## Dark navigation

- Каждый nav-item имеет прозрачный фон и не имеет обводки; hover/pressed-состояния в этот этап не добавляются.
- Активный пункт получает тонкую линию 2 px снизу, шириной по тексту с минимальным внутренним отступом 4 px с каждой стороны. Линия использует semantic action/brand accent Color, а не цвет текста.
- Цвет текста и подчёркивания берётся из семантического token primary text тёмной темы; неактивные пункты используют secondary text.
- Если inheritance token внутри экземпляра Header даёт недостаточный контраст, active text и underline MUST получить статический эквивалент `#F4F1EA` — светлый primary-тон Dark-темы.

## Проверка адаптивности

- На Desktop активный пункт не нарушает существующий горизонтальный ритм навигации.
- На Tablet сохраняется текущая компоновка; подчёркивание не меняет высоту Header.
- На Mobile активное состояние не создаёт отдельной заливки, не пересекается с меню и не увеличивает Header.
- Light-навигация использует такое же active-состояние: primary text и action/brand accent подчёркивание 2 px. Это обеспечивает одинаковый паттерн между темами.
- Подчёркивание добавляется как независимый absolute-слой корневого экрана, поэтому его позиция MUST учитывать положение секции Header (`y = Header.y + 50 px` для текущей Desktop-композиции), а не только локальные координаты экземпляра Header.
