## Purpose

Сделать страницы и изображения понятными поисковым системам и полезными по намерениям потенциальных клиентов, не прибегая к переспаму ключевыми словами.

## ADDED Requirements

### Requirement: Индексируемая архитектура

Значимые сущности MUST иметь серверно отданный HTML, уникальный URL и внутренние текстовые ссылки; `robots.txt` и XML sitemap MUST быть доступны в production.

#### Scenario: Обход без клиентского JavaScript
- **WHEN** поисковый робот запрашивает публичный маршрут
- **THEN** основной текст, заголовок, ссылки и метаданные присутствуют в HTML-ответе

### Requirement: Уникальные метаданные

Каждая индексируемая страница MUST иметь уникальные title, description, canonical URL и данные для социального превью.

#### Scenario: Страница проекта
- **WHEN** опубликован новый проект
- **THEN** его метаданные формируются из названия, типологии, локации и авторства без дублирования главной

### Requirement: Семантический контент

Страницы MUST использовать корректную иерархию заголовков, естественные поисковые формулировки и релевантный текст рядом с визуальными материалами.

#### Scenario: Поиск по услуге и локации
- **WHEN** поисковая система анализирует страницу услуги или проекта
- **THEN** она получает однозначные сигналы о типе работы, географии и авторе

### Requirement: Поиск по изображениям

Контентные изображения MUST иметь описательные имена, размеры, alt-текст по смыслу и контекстную подпись там, где она полезна; декоративные изображения MUST иметь пустой alt.

#### Scenario: Галерея проекта
- **WHEN** робот индексирует изображения проекта
- **THEN** каждое содержательное изображение связано с проектом, типом пространства и релевантным описанием

### Requirement: Структурированные данные

Сайт MUST публиковать валидный JSON-LD для `Person` или `ProfessionalService`, `WebSite`, хлебных крошек и подходящих творческих работ без фиктивных рейтингов.

#### Scenario: Проверка schema markup
- **WHEN** production-страница проверяется валидатором структурированных данных
- **THEN** обязательные поля валидны и соответствуют видимому контенту страницы

### Requirement: Контроль качества поиска

Production MUST быть подключён к панелям вебмастеров, а релиз MUST включать проверку индексации, sitemap и ошибок сканирования.

#### Scenario: После публикации
- **WHEN** сайт развёрнут на основном домене
- **THEN** sitemap отправлен, собственность подтверждена и создан базовый отчёт по запросам/страницам
