# Ближайшие задачи и встречи проекта

Статус: **accepted** — владелец поручил проверить план и сразу реализовать
сценарий 2026-09-25.

## Причина

Сводка проекта уже содержит пустой блок «Ближайшее по проекту», но не даёт
создать задачу или встречу, не загружает данные и фиксирует период в тексте на
семи днях. Полный lifecycle задач относится к R2, а календарь и встречи — к R5.
Для текущей сводки нужен совместимый вертикальный срез, который не объявляет
эти релизы завершёнными и не создаёт параллельную модель сроков.

## Объём изменения

- создать минимальные project-scoped записи задачи и встречи;
- добавить защищённые API создания и bounded feed ближайших записей;
- показать в заголовке блока компактные действия «Создать задачу», «Создать
  встречу» и «Настроить период»;
- заменить фиксированные 7 дней пользовательским периодом 1–90 дней;
- отобразить созданные записи с фильтром «Все / Задачи / Встречи»;
- обновить документацию и автоматические проверки.

## Не входит

Назначения исполнителей, granular privileges, task review/acceptance, выплаты,
редактирование/удаление, recurrence, общий календарь и календарная сетка остаются
за R2/R5. Их release checklist не закрывается этим изменением.

## Влияние

Добавляется совместимая PostgreSQL-миграция и новые optional API routes. SEO и
публичный сайт не меняются. Проектные данные остаются доступны только активному
участнику проекта или супер-администратору.
