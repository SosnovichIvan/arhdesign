# Documentation

OpenSpec описывает наблюдаемое поведение; OpenAPI — API контракт; Figma — визуальный контракт. Не дублировать схемы или макеты между ними.

При изменении API, конфигурации, запуска или эксплуатации обновлять README сервиса и `docs/architecture/`. Планируемое поведение не выдавать за реализованное.

Каждый OpenSpec change обязан указать context-impact до approval. После apply обновляются только затронутые файлы `.ai/context/`, затем выполняется `bash .ai/scripts/validate-context.sh` и semantic review с первичными источниками. Change не закрывается при устаревшем или противоречивом контексте.
