# Текущее состояние arhDesign

## Продукт и этап

- SEO-ориентированное портфолио архитектора-дизайнера; v1 — публичный сайт с контактным Go API.
- Код реализован: Next.js 16 App Router, TypeScript strict, React Server Components, Tailwind, семантические CSS tokens, FSD, Go API и PostgreSQL. Локальный Docker Compose-контур доступен через Caddy на `http://localhost/`; внешний VDS deploy ещё не выполнялся.
- SDD ведётся только через OpenSpec. Любая новая задача сначала оформляется и валидируется как change, затем принимается пользователем и только после этого реализуется. Перед Apply принятой задачи обязателен `$execution-state` routing с `source=openspec`; короткий `passthrough` не создаёт state.
