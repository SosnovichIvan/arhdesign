# Индекс контекста и источников истины

| Область | Первичный источник | Контекстный файл | Когда обновлять |
|---|---|---|---|
| Пользовательское поведение | `openspec/specs/`, active change | `project-state.md` | После реализации или изменения scope |
| Визуальные решения | Figma с `node-id` | `project-state.md`, `decision-log.md` | После approved дизайн-изменения |
| Долгосрочные выборы | User approval + OpenSpec | `decision-log.md` | После решения, влияющего на следующие задачи |
| Обратная связь | Пользовательское замечание | `feedback-log.md` | После замечания и после его разрешения |
| API | `openapi/` | `project-state.md` только ссылкой | После contract change |
| Инфраструктура | `infra/`, service docs | `project-state.md` только ссылкой | После изменения runtime/deploy |

Контекст не дублирует первичные источники. При расхождении приоритет: явное подтверждение пользователя → OpenSpec → Figma/OpenAPI/код в своей области → context.
