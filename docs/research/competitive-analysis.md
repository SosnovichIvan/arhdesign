## Выводы для arhDesign

1. Первый экран должен соединять визуальный образ и конкретику: кто, что проектирует, где работает и что делать дальше.
2. Проект — не просто картинка, а самостоятельный кейс и SEO landing page.
3. Для нового персонального бренда нельзя полагаться только на минимализм: нужны биография, процесс, параметры проекта и понятный контакт.
4. Изображения должны быть качественными, но производительность ограничивается заранее; Google рекомендует размещать качественные изображения рядом с релевантным текстом и использовать осмысленные имена/alt ([SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [Image SEO](https://developers.google.com/search/docs/appearance/google-images)).
5. Уникальные метаданные, sitemap и серверный HTML — базовые элементы, а не отдельная SEO-фаза ([Next.js Metadata](https://nextjs.org/docs/app/getting-started/metadata-and-og-images), [Next.js sitemap](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/sitemap)).

## Рекомендуемые дизайн-направления

### A — Editorial Calm (рекомендуемое)

Тёплый off-white, графит, оттенок натурального камня; Manrope + Cormorant Garamond. Асимметричная редакционная сетка, крупное hero-изображение, короткие тексты. Баланс премиальности, ясности и SEO.

### B — Gallery Grid

Холодный нейтральный фон, Golos Text, модульная сетка 12 колонок, нумерация и технические подписи. Лучше показывает большой объём работ и архитектурную дисциплину.

### C — Material Story

Мягкий песочный фон, Manrope + Prata, чередование полноэкранных медиа и текстовых историй. Наиболее эмоциональный вариант, но требует сильнейших фотографий и особенно строгого performance budget.

## SEO-кластеры для валидации владельцем

- бренд/имя архитектора;
- `архитектор-дизайнер + город`;
- `дизайн интерьера + тип объекта + город`;
- `архитектурный проект дома/квартиры + город`;
- `авторский надзор`, `комплектация`, `планировочное решение` — только если это реальные услуги;
- project long-tail: тип объекта + стиль/материал + локация.

Финальный keyword map нельзя завершить без имени, географии, услуг и данных из поисковых панелей после запуска.
