## Coverage

- Новый экран `GlobalProjectsCalendarPage`: statements 96.94%, branches 94.89%,
  functions 95.52%, lines 98.68% (`vitest` + V8).
- Backend: 90.0% statements по авторскому Go-коду; PostgreSQL integration включён
  в прогон.
- Общий frontend-отчёт репозитория пока не проходит установленный порог 90%:
  statements 87.96%, branches 79.39%, functions 86.74%, lines 94.67%. Это
  накопленный пробел ранее реализованных страниц; показатели нового календаря
  выше порога. Cypress проверяет сценарное покрытие, но instrumented JS coverage
  для Cypress в проекте пока не подключён.

## Визуальная проверка

- тёмная тема, desktop: навигация, toolbar, недельная шкала, плановый интервал,
  событие и режим списка;

  error, empty и partial states.

## Остаточный scope R5

Эта поставка закрывает общий календарь для уже существующих задач и встреч.
Отдельные календарные события, повторения, поставки/монтаж, редактирование и
удаление событий остаются задачами полного релиза R5.
