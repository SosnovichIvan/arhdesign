# QA-отчёт: глобальные чаты и техническая поддержка

Дата проверки: 28 сентября 2026 года.

## Область проверки

- страница глобальных чатов `/account/chats`;
- личные и групповые чаты, создание чата, поиск участников, отправка и чтение сообщений;
- постоянная учётная запись технического администратора;
- равные с супер-администратором права просмотра и управления;
- подписка технического администратора на Telegram-уведомления;
- регистрация неожиданных ошибок backend (HTTP 5xx и panic);
- регистрация runtime-ошибок frontend;
- форма жалобы или пожелания в правом нижнем углу;
- безопасная очередь доставки технических уведомлений без тел запросов, cookies, токенов, содержимого чатов и stack trace.

Ожидаемые ошибки клиента HTTP 4xx не считаются техническими сбоями и автоматически в Telegram не отправляются.

## Итог и блокирующий критерий

Функциональные, интеграционные, UI/E2E, Docker и визуальные проверки пройдены. Однако обязательный проектный порог 90% строк и ветвей для всего затронутого приложения пока не выполнен: общий backend имеет 87,5% statements, а frontend — 88,59% statements и 80,23% branches. Поэтому выпуск нельзя считать полностью готовым по действующей политике покрытия, пока недостающие ветви и сценарии не будут покрыты тестами.
