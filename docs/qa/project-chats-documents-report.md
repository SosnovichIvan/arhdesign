# QA-отчёт: чаты и документы проекта

Дата проверки: 30 сентября 2026 года.

## Область проверки

- возврат наверх лендинга после выхода из кабинета;
- список нескольких чатов проекта и область выбранного диалога;
- создание чата с обязательным именем;
- переименование чата и управление участниками;
- backend-проверка доступа к чатам и сообщениям по membership;
- страница проектной документации;
- загрузка, открытие и логическое удаление файла;
- повторное применение миграций к существующей PostgreSQL-схеме;
- локальная сборка и health checks Docker Compose.

## Проверенные сценарии Cypress

1. Пользователь открывает проект, создаёт именованный чат и видит его в списке
   слева рядом с областью сообщений.
2. Пользователь открывает документы проекта, загружает файл, открывает его и
   удаляет из активного списка.
3. Существующие сценарии проекта проверяют общий чат, сообщения между двумя
   пользователями, контекстные чаты задач, материалов и расходов.
4. После выхода пользователь возвращается в начало лендинга (`scrollY = 0`).

## Ограничения

- документы хранятся в PostgreSQL, максимальный размер одного файла — 10 МБ;
- автоматический отчёт покрытия в рамках этой проверки не формировался, поэтому
  соответствие проектному порогу 90% строк и ветвей этим отчётом не заявляется;
- автоматический прогон подтверждает все 36 существующих Cypress-сценариев, но
  не заменяет отдельное измерение покрытия строк и ветвей приложения.
