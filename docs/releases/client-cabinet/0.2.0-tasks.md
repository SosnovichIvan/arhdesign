## Приёмка релиза

- [ ] Все обязательные задачи R1 закрыты доказательствами; открытых blocker нет.
- [ ] Учетные данные/токены не попадают в логи, URL, Git и клиентский bundle.
- [ ] Бот принимает password только в registration confirmation, немедленно
  удаляет исходное сообщение, ничего не сохраняет и применяет rate limit;
  reset работает только в заранее связанном private chat без enumeration.
- [ ] Проект без заказчика доступен только супер-администратору и не создаёт
  фиктивную учётную запись заказчика.
- [ ] Backup восстановлен в отдельную PostgreSQL и результат сверки приложен.
- [ ] Нагрузочная приёмка прошла, VM остаётся ниже ресурсных порогов плана.
- [ ] Ежедневная сводка и тестовый критический alert имеют по одной логической
  delivery, доставлены подписанному супер-администратору и не содержат ПДн;
  неоднозначный Telegram timeout проверен как документированная at-least-once
  внешняя граница.
