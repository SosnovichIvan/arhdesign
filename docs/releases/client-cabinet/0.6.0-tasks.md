# R5 / `0.6.0` — календари

> Частичный вертикальный срез от 2026-09-25: в сводке проекта уже доступны
> создание встречи, фильтрация общей ленты и пользовательский период 1–90 дней.
> Это не закрывает задачи R5 ниже: общий/проектный календарь, timezone/DST,
> recurrence, редактирование, удаление и переходы к источникам остаются в scope
> `0.6.0`. Контракт среза: `openspec/changes/add-project-upcoming-items/`.

Статус: **planned**  
Зависит от: R2–R4  
Результат: проектный календарь показывает один проект, общий календарь —
доступные пользователю планы по всем проектам без утечки закрытых объектов.
