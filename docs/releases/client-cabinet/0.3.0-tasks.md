# R2 / `0.3.0` — участники, привилегии и задачи

> Частичный вертикальный срез от 2026-09-25: в сводке проекта уже доступны
> создание минимальной задачи с будущим дедлайном и bounded feed ближайших
> событий. Это не закрывает задачи R2 ниже: назначения, granular privileges,
> полный lifecycle, комментарии, выплаты, редактирование и удаление остаются в
> scope `0.3.0`. Контракт среза: `openspec/changes/add-project-upcoming-items/`.

Статус: **planned**  
Зависит от: R1 / `0.2.0`  
Результат: участники получают права внутри конкретного проекта, работают только
со своими разрешёнными задачами, а заказчик и администраторы управляют проверкой.
