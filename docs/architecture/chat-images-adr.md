# Изображения в личных и проектных чатах

26 ноября 2026 · Решение реализовано в рабочей ветке.

Изображение принадлежит одному чату. Его можно прикрепить без текстового сообщения, открыть в просмотрщике, закрепить или открепить. В личных и групповых чатах список, переписка и файлы доступны участникам с действующим членством. В проектных чатах тот же доступ имеют администраторы платформы. Обычному пользователю нужны действующее участие в проекте и членство в чате. Для контекстного чата дополнительно действуют права на исходную запись. Изображение может удалить его автор или пользователь с правом управления чатом.

Для хранения выбран PostgreSQL, как и для проектных документов. Объектное хранилище потребовало бы отдельной инфраструктуры и механизма, который отзывает ранее выданные ссылки. Новый API хранит и выдаёт JPEG, PNG и GIF до 10 МиБ и 40 мегапикселей по URL с проверкой сессии и прав. Ответы с изображениями не кэшируются. Лимиты нагрузки и объём хранения в эксплуатации пока не измерены.

Миграция 022 добавляет пустую таблицу `chat_images` и индекс для постраничного чтения. Два внешних ключа подтверждают принадлежность файла к выбранному виду чата. Переход сохраняет существующие данные и позволяет применить миграцию до обновления приложения. При откате приложения таблица остаётся на месте. Возврат к предыдущей версии кода также возвращает её правила доступа к чатам, поэтому для ошибок авторизации предпочтительно исправление вперёд.

Загрузка сохраняет метаданные и байты одной транзакцией. Повтор с тем же UUID, тем же файлом и тем же автором возвращает существующую запись. Удаление очищает байты и оставляет запись для защиты от повторного создания по прежнему ключу. Прикладной API читает страницы по позиции закрепления, времени создания и UUID. Проверки на PostgreSQL охватывают применение миграции к существующим чатам, попытки чтения по прямому адресу, повтор загрузки, закрепление и удаление.
